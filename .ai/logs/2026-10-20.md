## Session: add/remove teams + new-season popup from toolbar

### Requirements (from user)
- Be able to add and remove teams.
- At start/end of a season, a button to create a new season (like the old admin one), but as a POPUP:
  - lists all registered teams to choose from, with the previous year's teams PRE-SELECTED.
  - also allow adding brand-new teams.
- The button must live in the TOOLBAR. The old Admin page "Create new Season" button should be REMOVED.
- Decisions confirmed with user: persist teams to DB (not teams.txt); preselect previous season's teams; dedicated toolbar icon button; remove the admin button.

### Backend changes
- `core/peristence/dtos/Team.java`: added `active` boolean column (default true). Soft-delete flag.
- `api/dtos/TeamSimpleDTO.java`: added `active` field.
- NEW `core/services/TeamService.java`: `addTeam(name)` (reactivates a retired same-named team, else creates), `removeTeam(team)` (soft-delete: sets active=false; history preserved).
- `api/controllers/RestTeamsController.java`: added `POST /rest/teams/` (form param `team_name`) and `DELETE /rest/teams/{id}`. `GET /rest/teams/` now includes `active`.
- `core/services/SeasonService.java`: `createSeason(List<Integer> teamIds)` — when team ids are supplied, only those teams join the season; otherwise falls back to teams.txt (backward compatible). Kept old `createSeason()` delegating with null.
- `api/services/OperationsService.java`: overload `createSeason(List<Integer> teamIds)`.
- `api/controllers/RestOperationsController.java`: `POST /rest/ops/season/create` now accepts an optional JSON body = list of team ids. Added `GET /rest/ops/season/previous_teams` returning the previous season's team ids (for preselection).
