## Session: fix New Season dialog resetting selections on add team

- User reported: after adding a team in the Start New Season popup, all checkbox selections above reset.
- Cause: `NewSeasonDialog.loadData()` rebuilt the `selected` map from scratch (`previousIds` + new team id), discarding user toggles. Remove team did the same.
- Fix (`ui/src/components/NewSeasonDialog.jsx`): `loadData(preselectId, preserveSelections)` now merges with previous selection via functional `setSelected`, keeping user choices; newly added team defaults selected; inactive teams are unselected. Add and remove now call `loadData(..., true)`.
