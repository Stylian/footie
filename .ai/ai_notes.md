# AI Guidelines

## Session Logs
Each session is logged in `.ai/logs/YYYY-MM-DD.md`. Read the latest log at the start of each session to understand context, user preferences, and recent changes. Create a new log file for each new session.

## Rules
- Always read `.ai/project_notes.md` for project-specific information before starting work
- Keep responses concise and direct
- Explain technical terms simply when the user is not a developer
- Prefer editing existing files over creating new ones
- Use lowercase filenames for markdown files
